# CCNR-RP 使用指南（v1.0.4）

> **CCNR-RP** 是一个 Forge 1.20.1 阵营角色扮演模组：
> 多角色档案 / 阵营关系 / 职业与装备 / 状态机（观察→激活→部署→存活→死亡→冷却→复活）
> / 经验结算 / 阶段事件 / 动画演出 / 刷新波与招募 / 游戏结束疏散裁定。
> 界面为 **"SCP:NET 机密终端"** 风格的三栏网格。

---

## 1. 安装

1. 用 **HMCL / 官方启动器** 选择 **Forge 47.2.0+（1.20.1）** 版本。
2. 把 `ccnr_rp-1.0.4.jar` 放入 `.minecraft/mods/`（与 ccnrcom-1.1.0 同目录即可；`corpse` 为可选依赖，缺失时自动使用原生死亡降级）。
3. 进入世界（单人 / 局域网 / 服务器均可）。首次启动会自动生成默认配置：
   - `.minecraft/config/ccnr_rp/factions.json`（阵营+职业，含精简样板：3 个样例阵营与 4 个样例职业）
   - 同目录 `phases.json` / `events.json` / `animations.json` / `spawn_waves.json`
4. 按 `K`（可在按键设置里改键，类别 **CCNR-RP → 角色管理界面**）打开角色管理终端。

> 单人/局域网：客户端配置即服务端配置；连远程服务器时，**服务器与客户端都要装同一版本**，
> 阵营/职业/阶段/事件等以**服务器**的配置为准。

---

## 2. 快速开始（3 分钟上手）

1. 按 `K` 打开终端。左列点选机构（默认「全部」）。
2. 右下角「创建角色」卡输入 **名字** → 点 **阵营** 切换 → 点 **职业** 切换 → 填背景 → 点 **创建角色**。
3. 中间列表出现你的角色后，选中它，点 **选择** → **激活**（进入在场状态）。
4. 管理员部署或自部署（`selfDeploy=true` 的职业可点 **部署**）后，你即携带职业装备在外生存。
5. 死亡/掉线判死 → 角色**直接变成观察模式**并**强制切换旁观者模式**：复活后**传送回死亡地点**，进旁观者时就在尸体旁边（不改变出生点）；**结算完成后再次强制刷成观察者身份**，观察者身份**自动刷成旁观者模式**（每 2 秒轮询，未部署玩家强制旁观）；观察者时屏幕下方**常驻提示「观察中，按 K 进行部署」**（K 为实际绑定按键）；**背包（E）打开时**右下角显示状态栏（与事件横幅一致，不再常驻游戏内；职业=观察者 / 阵营=观察模式 / 血量=不适用），K 面板可打开查看；复活冷却只锁「自己职业自部署」，事件刷新波/复活波可能向你发 **招募邀请**（屏幕右侧卡片，右下角弹窗接受/拒绝），复活波/FORCE_PICK 可无视冷却强制复活（部署时自动切回生存）。
6. 进行中的事件横幅仅在**背包（E）打开时**显示在背包界面上方；游戏内 HUD 上不再常驻。
7. 事件结束时管理员运行 `/rp gameover` 触发游戏结束演出；**经验不自动结算**（结算仅死亡退场或 `/rp settle` 触发）。

## 3. 终端界面（K 键）操作详解

### 三栏网格

| 位置 | 内容 | 操作 |
| --- | --- | --- |
| **左栏「机构分类」** | 圆形徽章导航：全部 + 各阵营 | 点击按阵营过滤角色列表 |
| **中栏「角色档案」** | 角色卡片：头像/名字/阵营·职业/状态胶囊(AM 存活·M 死亡·OB 观察)/冷却 | 点击选中；滚轮滚动 |
| **右栏「详细资料」** | 档案卡 + 3D 模型预览 + 战术装备槽 + 操作按钮 + 皮肤上传 + 创建表单 | 见下 |

### 徽章颜色 = 机构等级（tier）

- 🟡 **金色 = 1 级**（最高机密，如 QDF/QSA/QSO）
- 🔵 **蓝色 = 2 级**（标准机构，如 量子科学/麦迪逊）
- 🟢 **青色 = 3 级**（普通编制，如 后勤）

徽章图形：盾牌 / 爪印 / 风暴 / 六边形 / 之眼 / 靶心 —— 在 `factions.json` 中用 `icon` 字段切换。
`img:<名>` 为**图片徽章**：取服务器素材库 `config/ccnr_rp/textures/<名>.png`（由服务器中央下发，客户端自动下载），
模组不再内嵌图标——未上传/未配置时仅显示底色徽章盘（无图形）。

### 3D 模型预览与装备槽

- 预览是你的**真实玩家模型**：上传过皮肤的档案自动显示定制皮肤，否则为默认 Steve。
- 预览默认穿戴 **下界合金战术重装 + 剑盾**（仅为预览展示），**移动鼠标可旋转模型**。
- 预览框底部是 **头 / 胸 / 腿 / 背** 四个战术装备槽位图标。

### 选中态（红色）

- 左列机构选中、中列角色选中均为 **红底白字 + 红色高亮线 + 警戒线**。

### 关闭

- 右上角 **✕** 按钮，或 `Esc`。

## 4. 指令一览（`/rp`）

> 管理类子命令需要管理员权限（op）。

### 阵营与关系
| 指令 | 说明 |
| --- | --- |
| `/rp faction list` | 列出阵营/组/关系 |
| `/rp faction relation <a> <b>` | 查询关系 |
| `/rp faction relation <a> <b> set <hostile|neutral|friendly>` | 设置关系 |
| `/rp faction group list` | 列组 |
| `/rp faction group create <id> <成员...>` | 创建组（批量声明） |
| `/rp faction group relation <g1> <g2> <type>` | 组×组关系 |

### 职业
| 指令 | 说明 |
| --- | --- |
| `/rp profession list` | 列出职业 |
| `/rp profession create <id> <factionId> <selfDeploy true|false>` | 创建职业 |
| `/rp profession save <id> [--hotbar|--full]` | 把当前背包/装备存为该职业配装 |
| `/rp profession load <id>` | 套用职业配装 |

### 角色
| 指令 | 说明 |
| --- | --- |
| `/rp character list` | 刷新你的角色列表（GUI 数据） |
| `/rp character create <name> <faction> <profession> [background]` | 命令行创建（与 GUI 规则一致） |
| `/rp character select|delete|observe|activate <id>` | 选择/删除/观察/激活 |
| `/rp character cooldown <id>` | 查看剩余冷却 |

### 状态与经验
| 指令 | 说明 |
| --- | --- |
| `/rp state` | 你的角色状态（存活/观察/死亡/冷却） |
| `/rp kill <玩家>` | 判死（含遗体与冷却） |
| `/rp xp` / `/rp level` | 经验 / 等级 |
| `/rp xp add <玩家> <数值> <标题>` | 给玩家添加自定义记分项目（标题+数值，可为负；入待结算列表，结算时计入） |
| `/rp evac <SAFE_RESCUE|DIED|OBSERVING_END|STAY_BEHIND>` | 设置疏散方式 |
| `/rp settle all` | 全员结算（经验列表求和） |

### 事件与阶段
| 指令 | 说明 |
| --- | --- |
| `/rp event list` / `/rp event trigger <id>` / `/rp event end` / `/rp event enable <id> <true|false>` | 事件 |
| `/rp phase list` / `/rp phase set <id>` / `/rp phase advance` | 阶段表推进 |
| `/rp gameover` | 触发游戏结束演出（不自动结算经验） |

### 动画与刷新
| 指令 | 说明 |
| --- | --- |
| `/rp animation list` / `/rp animation play <id>` | 动画片段 |
| `/rp spawn list` / `/rp spawn trigger <id>` / `/rp spawn enable <id> <true|false>` | 刷新波 |

## 5. 配置文件

| 文件（`.minecraft/config/ccnr_rp/`） | 内容 |
| --- | --- |
| `factions.json` | 阵营（`icon` 徽章图形 / `tier` 等级 1-3 / `music` 阵营出场音乐）、组、关系、职业（含 `loadout` 装备与 `music` 出场音乐） |
| `phases.json` | 事件阶段表（时长/顺序） |
| `events.json` | 事件定义（触发器/任务/阶段） |
| `animations.json` | 动画序列（特效/音效/字幕） |
| `spawn_waves.json` | 刷新波/复活波（模式/数量/队伍） |
| `audio/*.wav` | **服务器素材库（音乐）**：全部由服务器控制，客户端进服自动下载缓存 |
| `textures/*.png` | **服务器素材库（阵营图标）**：`img:<名>` 优先取这里，由服务器控制 |

- 缺失或为空时自动回退内置默认值（`assets/ccnr_rp/defaults/`）。
- 运行时数据在 `world/ccnr_rp/`：`characters.json`、`xp_ledger.json` 等（原子写，损坏保留 .bak）。
- **素材中央下发**：音乐与阵营图标全部由服务器控制。客户端进服时收到素材清单（名称+哈希），
  与本地缓存（`config/ccnr_rp/assets-cache/`，按哈希对比）比对后自动下载缺失/变更项；
  播放与渲染一律使用服务器下发版本，客户端无需手动分发音乐/图标文件，也无法用本地文件替换。

### 出场音乐与优先级（高→低）

部署入场电影的音乐解析链：**启动程序指定音乐 > 职业音乐 > 阵营音乐**。

1. **启动程序（启动器）指定音乐**（优先级最高，客户端生效）：在启动器里加 JVM 参数
   `-Dccnr_rp.entrance_music=<路径>`（HMCL/PCL：版本设置 → 高级设置 → JVM 参数），
   或用环境变量 `CCNR_RP_ENTRANCE_MUSIC`。路径相对 `config/ccnr_rp/` 或绝对路径，WAV 格式。
2. **职业音乐**：职业定义里 `music` 字段（管理器职业表单「出场音乐」）。
3. **阵营音乐**：阵营定义里 `music` 字段（管理器阵营表单「出场音乐」；factions.json 直接编辑亦可）。

某一级未配置则自动落到下一级；全部未配置则入场电影静默无音乐。

> **音乐文件由服务器中央下发**：职业/阵营音乐相对路径（`audio/<文件名>`）一律从服务器素材库解析，
> 客户端进服后**异步下载**缓存（后台线程，按哈希增量更新，不卡游戏），不再要求玩家手动放置音乐文件；
> 在服务器 `config/ccnr_rp/audio/` 替换或上传新音乐后，客户端自动更新。
> 同步期间左上角显示「正在同步数据…」，**同步完成前禁止部署/复活**（服务端强制，客户端回执后放行）；
> 同步完成后自动打开角色面板（与按 K 同一入口，受设置 openPanelOnJoin 控制）。

### 音乐上传与选择（管理员）

1. 管理器「职业/阵营」表单的**出场音乐**输入框支持补全提示：输入关键字过滤已上传音乐，点选或 ↑/↓+回车 填入。
2. 上传新音乐：表单内「音乐文件路径或 URL」填本地 .wav 路径或 http(s) 直链 → 点**上传音乐**。
   服务端校验 WAV 格式（≤20MB）后存入 `config/ccnr_rp/audio/`（服务器素材库），全服列表与素材清单即时更新，
   客户端自动下载；播放路径填 `audio/<文件名>` 即可。

## 6. 皮肤上传

1. 准备 **64×64 或 64×32 PNG**（MC 皮肤规格，< 256KB）。
2. 选中角色 → 右栏「皮肤 PNG 路径或 URL」填**本地绝对路径**（如 `/Users/bananaxiao/Pictures/skin.png`）或 **http(s) 图片直链**。
3. 点 **上传皮肤** → 服务端按规格校验并按哈希去重存储；预览模型与列表头像立即换成你的皮肤。
4. **扮演显示**：部署角色后，全服玩家看到你以该角色的皮肤出场（服务器按哈希缓存，重复上传只存一份）。

## 7. 常见问题

| 现象 | 原因与解决 |
| --- | --- |
| 左上角红字 `ccnr_rp.xxx` | 旧版本漏翻译，更新到 1.0.4（各语言包键已同步） |
| 职业按钮「职业: (暂无配置)」 | 配置里没有职业，管理员执行 `/rp profession create <id> <阵营id> <true/false>` |
| 左列徽章全部灰色 | 旧配置无 `icon`/`tier`；替换 `factions.json` 为带该字段的版本或重装生成 |
| 3D 预览不显示 | 需在世界内按 K（主菜单不可用）；本机未装 Skyblock 等禁用 GUI 材质包 |
| 招募邀请没弹 | 需等待事件刷新波/复活波（RecruitOfferS2C），收到后右侧卡片 60 秒内点「接受」 |
