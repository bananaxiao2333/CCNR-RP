# CCNR-RP 界面主题设计 · 黑白灰军用终端（docs/14）

> 目标：把 in-game 界面视觉统一为「黑白灰军用终端」，与 Web 管理面板（ccnr-rp-gui / src/admin）保持一致。
> **主题 v4** 替换原 **v3「CCNR:NET 机密终端」**（冷暗科技金属底 / 青色主色 / 金·蓝徽章 / 高饱和正红选中）。
> 本设计只改「视觉层」（颜色/描边/选中态/文字层级/容器装饰），**不触碰**布局、几何、行为、配置、网络、存档与运行时逻辑。

## 1. 设计语言（一句话）

> 近黑冷暗底 / 白·灰等宽文字 / 细灰边 / **白 = 强调**（选中反白）/ **红 = 警示危险** / **灰阶徽章**（机构等级）。
> 除红色警示外全程无彩色，仅以明度（白 > 亮灰 > 暗灰）划分层级。

- 底色：近黑（#000 ~ #141414），面板灰阶底、深色卡片。
- 文字：白（主）/ 亮灰（次）/ 暗灰（弱），等宽字体（MC 字体近似）。
- 边框：细灰（#333 / #666），四角 L 型角标。
- 强调：白色（按钮主操作、选中反白、游标、徽章亮阶）。
- 危险：正红（#FF3B30 / #FF4A40），唯一保留彩色。

## 2. 设计令牌（RpTheme.java 常量，v4）

| 令牌 | ARGB | 说明 |
| --- | --- | --- |
| OVERLAY | 0xB3141414 | 面板半透明底（近黑） |
| BG_DEEP | 0xCC0A0A0A | 更深背景 |
| PANEL_BG / _ALT / _EVEN | 0x99141414 / 0xB3222222 / 0x9B161616 | 卡片 / 列表底 |
| PANEL_BORDER | 0xFF333333 | 细灰边 |
| PANEL_BORDER_BRIGHT | 0xFF666666 | 亮灰边 |
| TEXT_PRIMARY | 0xFFFFFFFF | 主文字（白） |
| TEXT_SECONDARY | 0xFFA0A0A0 | 次文字 |
| TEXT_DIM | 0xFF666666 | 弱文字 |
| CYAN（= 主色） | 0xFFFFFFFF | 白色强调 |
| CYAN_DIM | 0xFF888888 | 灰强调 |
| GREEN（= 正面/正常） | 0xFFB4B4B4 | 中性亮灰 |
| RED / RED_DIM / RED_LINE | 0xFFFF3B30 / 0xFF8C2320 / 0xFFFF4A40 | 危险 / 警戒 |
| GOLD（= 徽章亮阶） | 0xFFB4B4B4 | 灰阶徽章 |
| STATUS_ALIVE / _DEAD / _OBSERVING | 白 / 红 / 灰 | 状态色 |

**等级徽章灰阶**（tierColor）：
- 1 级（最高机密）→ 白（TEXT_PRIMARY）
- 2 级（标准机构）→ 亮灰（TEXT_SECONDARY）
- 3 级（普通编制）→ 暗灰（TEXT_DIM）

## 3. 与前端映射（ccnr-rp-gui App.css / theme.js）

| 前端令牌 | 值 | 模组映射 |
| --- | --- | --- |
| --bg / --bg-secondary | #000 / #0a0a0a | 近黑底 |
| --border / --border-active | #1a1a1a / #333 | 细灰边 |
| --text / --text-secondary / --text-muted | #fff / #888 / #444 | 白 / 亮灰 / 暗灰 |
| --accent | #fff | 主色 = 白（CYAN） |
| --danger | #ff3333 | 红 = RED_LINE |

> 语义完全一致；因 MC 为栅格渲染、无 CSS 盒阴影 / 字体渐变 / 反锯齿，取值取近似而非逐像素。

## 4. 关键组件实现

- **terminalPanel / card**：近黑底 + 灰描边。
- **selectedBar（选中态）**：**白底反白字** + 白左线，对齐前端 selected 反白；选中行文字须用 `RpTheme.ACCENT_TEXT`（深色）以保证白底可读。
- **RpButton**：`primary`=白底黑字 / `secondary`=暗底灰边白字 / `danger`=红边红字。
- **RpScrollbar**：游标用 CYAN（现为白）。
- **RpIcons.badge**：灰阶环（按 tier）+ 白色图形。
- **tag()**：`"[ 分类 ]"`。
- **scanlines**：每 3px 一条微亮白线（屏幕质感）。

### 5.1 终端容框完整视觉层（2.20.1，格式/细节/布局层）

> v4 只迁移了「调色板」，本层补齐前端 `App.css` 的**容器装饰**（非颜色，属格式/细节/布局）：

- **`RpTheme.terminalFrame()`**：素版面板（近黑底+灰描边）之上叠加**四角 L 型角标**（`cornerBrackets`，此前已定义但未调用）+ **顶部高光 rail**（低透明度，对齐 `.terminal-panel::before` 顶部渐变细线）。用于**顶层面板**（`CharacterManagementScreen` / `RpAdminScreen`）；内嵌弹窗/小卡片仍走 `terminalPanel`（无角标/网格）。
- **`RpTheme.gridOverlay()`**：面板细灰网格叠层（对齐 `.terminal-panel::after` 的 100px 网格，32px 步进、低透明度），呈「军用终端底格」质感。
- **CRT 扫描线**：`CharacterManagementScreen` 与 `RpAdminScreen` 在内容层之上叠加 `RpTheme.scanlines()`（对齐 `body::before`），此前仅 `FactionGraphScreen` 有。

### 5.2 K 面板 / 管理面板结构与标签对齐（2.20.2，结构/文案层）

> 在颜色 + 容器装饰之上，把**结构标签与文案**对齐参考 ccnr-rp-gui（`Terminal.jsx` / `DetailPanel.jsx` / `AdminPanel.jsx`），非仅改色：

- **顶部栏**：`[CCNR] TERMINAL` + `LV.x // STATUS: y` + `[ ADMIN ]` / `X`。
- **列头**：`[ NAV ]` / `[ POSITIONS ] [n]` / `[ DETAIL ]`；导航项 `[ ALL ]`、`[ 阵营名 ]` 统一方括号。
- **详情面板分区**：`ID: x // FACTION: y`、`[ LV.REQ: x | CURRENT: y ]`、`PERSONNEL: a/b // FACTION: c/d`、`// PREVIEW`、`EQUIPMENT`、`// PROFILE`。
- **部署按钮**：`[ DEPLOY ]` / `[ REDEPLOY ]` / `[ REQ LV.x ]` / `[ FULL occ/lim ]`。
- **管理面板**：页签 `[ 设置 ]` 方括号、标题 `[CCNR] ` 前缀。
- **标签语言策略**：结构标签用参考的**英文终端式**；内容（职业名/阵营名/画像文本）仍用本地化文本；zh_cn 与 en_us 键集一致（LangFileTest 保障）。

### 5.3 与前端一致性边界（重申）

- 前端为 CSS 渲染（渐变/box-shadow/抗锯齿），MC 为 int 色值、无渐变/阴影/抗锯齿，呈现为「同设计语言的近似值」，非逐像素相同。
- 扫描线/网格/角标均为**低透明度/细线**，不压过内容可读性；仅顶层主容器使用，内嵌弹窗保持素版。

## 6. 边界与注意（为什么 / 如何失效）

- **只改视觉**：布局 / 几何 / 行为 / 配置 / 网络 / 存档均不动，仅颜色与描边。
- **脱离主题的风险**：若新增界面直接写彩色字面量而不走 `RpTheme`，会与黑白灰终端不一致；当前已全局扫描，余下仅 `STATUS_OBSERVING`（0xFF7E8A8F，观察态弱灰-青）被识别为「非纯中性」，属刻意保留的弱色。
- **白色选中可读性**：反白依赖 `selectedBar` 白色底 + 该行文字用 `ACCENT_TEXT`（深色）。若某处对反白行仍写白字会白底白字不可读（本次已逐一排查选中行）。
- **与前端一致性边界**：前端为 CSS 渲染，MC 为 int 色值、无渐变/阴影/抗锯齿，呈现为「同设计语言的近似值」，非逐像素相同。
- CI 无颜色守护（无快照测试），一致性靠人工 review + 前端对齐；改色后跑 `spotlessApply` + `build -PrunTests`。
