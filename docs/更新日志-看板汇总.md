# CCNR-RP 更新日志（看板任务汇总）

> 覆盖看板全部任务（版本区间约 2.0.0 → 2.14.2；带【评审中】为已实现待实机验收）。

## 一、核心架构与重构
· 核心重构：删除角色实体，状态 / 经验 / 复活冷却上移到用户层（唯一身份 = 用户档案）
· 配置服务器侧化：本地配置改为服务器同步，客户端只遵从服务器值
· 统一部署 / 退场 / 结算管道：一个函数 + 行为 flag，删除征召分支文案
· 修复进服自动打开面板
· 收尾：命令树 / 语言包 / 测试 / 文档 / 构建验证全绿（66 用例 0 失败）

## 二、职位与部署系统
· 职位模型：增加 unlockLevel 解锁等级字段，取消 selfDeploy 自选
· 部署与刷新按「职位 + 用户等级解锁」门控，替换 selfDeploy 判定
· K 面板改为「职位选择器」：选中即部署 + 需求等级展示（未达红色）+ 部署按钮变红
· 取消 K 面板打开限制：任意时刻可打开
· K 面板 3D 人物名字板可关闭（只留人物 + 装备）
· 修复：部署前清空背包，防止遗留背包物品
· 修复部署流程：先播 CMDCam 入场动画（标题文字电影），动画完毕后再传送到出生点【评审中】
· 入场动画全程强制旁观者；电影 HUD 与 CMDCam 场景同一时刻播放；未设定 CMDCam 时开局直接落位切生存【评审中】

## 三、尸体系统
· 修复：尸体无皮肤（应显示玩家皮肤）+ 尸体名字改为「职位 + 玩家名」（如「警察 小明」）【评审中】
· 换肤注入修复（clean profile）+ 尸体 mod 联动：尸体显示角色名与角色皮肤
· 尸体身份非入侵注入（不改尸体 mod 本体/jar）：保持玩家真实 UUID（皮肤）+ 名字牌「职位 + 玩家名」

## 四、皮肤系统
· 皮肤系统增强：URL 上传 + 哈希缓存 + MC 规格校验 + 扮演全服显示角色皮肤 + 查看界面真实皮肤/职位装备
· 皮肤回收：无角色引用的皮肤按哈希清理
· RP 模组兼容旧版（64x32）皮肤：上传/渲染自动转换为现代 64x64
· 重构后删除旧皮肤系统（上传/预览/缓存/换肤注入），皮肤以玩家本人皮肤为准

## 五、音乐系统
· 音乐管理：管理员上传音乐 + 管理面板选择补全提示
· 音乐传递优先级：启动程序指定 > 职业音乐 > 阵营音乐
· 音乐格式全面切换 OGG（WAV 体积过大弃用）：上传/存储/清单 .ogg + OggS 校验；内嵌 jorbis 解码播放；scripts/convert-music-to-ogg.sh 批量转换

## 六、阵营、经验与显示
· 阵营图标展示规范化：选岗/创建角色等补齐阵营徽章 + 统一徽章绘制封装
· 经验结算显示改右下角一条一行：红色扣分/绿色加分，如「-10 死亡」
· 修复：征召显示
· 刚入服 5 秒：右下角三状态栏（职位/阵营/血量）常驻显示（不管背包是否打开）

## 七、观察者与规则
· 修复：观察者时轮询清空玩家背包
· 修复：观察者模式下 better_looting 仍然可以拾取物品——拾取拦截（EntityItemPickupEvent 取消）
· 观察者拾取真正禁止：Inventory.add 入口拦截（Mixin，物品原地不动，不消失不重复）
· 观察者模式强制旁观者（动画全程 + 轮询兜底）

## 八、管理器与 CMDCam 联动
